# workspace/ (deprecated on this branch)

On this branch, **`workshop/` is the canonical namespace** for lab/architecture scaffolding.

This `workspace/` directory is intentionally kept as a minimal deprecation marker.
Please use:
- `workshop/scripts/`
- `workshop/schemas/`
- `workshop/patches/`
- `workshop/decisions/`

No public/runtime paths are redirected by this marker.
