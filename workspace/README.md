# workspace/ — Authoring Layer (Layer A)

This directory is the **private authoring and workshop layer** for the research infrastructure.
It is separate from the public-facing website and graph assets.

## What belongs here

| Subdirectory | Purpose |
|---|---|
| `schemas/` | JSON Schema definitions for workspace object types (SourceQuote, Claim, DecisionTrace, etc.) |
| `scripts/` | Build, export, lint, and patch-application scripts |
| `patches/` | Organized patch files. `pending/` = not yet applied. `applied/` = merged into canonical graph. |
| `evidence/` | Working evidence objects and samples |
| `decisions/` | Machine-readable DecisionTrace records (one JSON file per significant decision) |
| `narratives/` | NarrativePreset and NarrativeStep objects for scrollytelling management |
| `audits/` | (Phase 2) Consolidated audit documents — currently in `docs/` at repository root |

## What stays outside this directory

- `grc20-these-mael-rolland-v96.json` — canonical graph snapshot (repository root, read-only from here)
- All HTML/CSS/JS files — public site (not modified by workspace scripts)
- `narrative-anchors.json` — derived output (regenerated by `build-export.mjs`)
- `docs/` — audit documents (Phase 2: will move here)
- `Migration/` — migration ZIPs and agent instructions (Phase 2: will move here)
- Root `patch_*.json` files — patches awaiting consolidation (Phase 2: will move to `patches/pending/`)

## Key design principles

1. **The canonical graph is read-only from this layer.** Scripts read from `grc20-these-mael-rolland-v96.json` and write export snapshots to `../public/exports/`.
2. **Legacy content is `legacy_canonical` by default.** All entities and relations in v96 are treated as `legacy_canonical` status — assumed valid but not individually reviewed.
3. **No bulk rewrites.** Scripts annotate or report; they do not mass-modify the canonical graph.
4. **Dry-run first.** Every script supports `--dry-run` mode that reports what would happen without writing files.

## Scripts

```bash
# Lint the canonical graph (report only, no writes)
npm run lint

# Export a public snapshot (dry-run)
npm run export -- --dry-run

# Export a public snapshot (real write to public/exports/)
npm run export

# Apply pending patches (dry-run)
npm run apply-patches -- --dry-run
```

## Status model

See `schemas/status-model.json` for the canonical trust/lifecycle status definitions.

The status promotion path is:
```
raw → extracted → linked → needs_review → validated → published
```

Legacy v96 content starts at `legacy_canonical` (parallel track, not requiring promotion).

## Object types (workspace-layer, not yet in canonical graph)

- **Claim** — Explicit analytical proposition with evidence links
- **DecisionTrace** — Record of an architectural or editorial decision
- **NarrativePreset** — Guided narrative sequence for scrollytelling
- **NarrativeStep** — One step within a NarrativePreset
- **ValidationEvent** — Record of a validation action on a graph object

These are stored as JSON files in this directory and are NOT yet wired into the canonical graph's `relation_types`. They are promoted to the graph schema in Phase 3.
