# Vue « Qui gouverne réellement ? » — V2 corrigée

## Pourquoi corriger
La version précédente était insuffisante :
- elle n'avait pas de colonne explicite `Gouvern.`
- elle n'avait pas de colonne `Struct.`

Or la thèse est explicitement structurée par la gouvernance :
- introduction : révéler l'indicible gouvernance des CM
- chapitre II : au-delà de la revendication d'une absence de gouvernance
- chapitre III : la gouvernance discrète des CM dévoilée par leurs crises

La vue doit donc montrer à la fois :
- l'ossature du manuscrit
- les formes de gouvernement
- les catégories, groupes, arènes, personnes, cas et références

## Matrice recommandée : 8 colonnes × 6 lignes

### Colonnes
1. Struct.
2. Gouvern.
3. Catégories
4. Organisations
5. Groupes
6. Arènes
7. Personnes
8. Cas / Réf.

### Lignes
1. Problématisation
2. Coordination
3. Décision
4. Conflit
5. Maintenance
6. Sources

## Sens des colonnes

### Struct.
- ThesisSection
- ChapterSection
- Argument
- NarrativeCluster

### Gouvern.
- GovernanceProcess
- GovernanceConflict
- ProtocolProposal
- CrisisPhase
- concepts directement gouvernants : gouvernance polycentrique, gouvernance duale, mise en crise, remise en ordre, politique de crises

### Catégories
- StakeholderCategory

### Organisations
- Institution
- Organization

### Groupes
- StakeholderGroup

### Arènes
- GovernanceArena
- GitHub, mailing lists, réunions, procédures

### Personnes
- personnes agissantes dans la gouvernance effective

### Cas / Réf.
- partie haute : CrisisEvent, cas révélateurs
- partie basse : Reference, SourceQuote, PrimarySource, Corpus, AcademicWork, auteurs théoriques

## Règles
- ne pas absorber la gouvernance dans `Arènes`
- ne pas supprimer `Struct.`
- ne pas envoyer les personnes agissantes en colonne finale
- `Cas / Réf.` reste une colonne terminale bien décrochée
- conserver halos, lisibilité mobile et esthétique historique

## Exemples
- Gouvernance polycentrique -> Gouvern. / Problématisation
- Gouvernance duale -> Gouvern. / Problématisation
- Politique de crises -> Gouvern. / Maintenance
- II.3 Au-delà de la revendication d'une absence de gouvernance ! -> Struct. / Problématisation
- III.3 Une gouvernance publique d'exception -> Struct. / Conflit
- Peter Wuille -> Personnes / Maintenance
- Greg Maxwell -> Personnes / Décision
- GitHub Bitcoin Core -> Arènes / Maintenance
- Bitcoin-dev Mailing List -> Arènes / Coordination
- CVE-2018-17144 -> Cas / Réf. / Maintenance
- The DAO -> Cas / Réf. / Conflit
- Susan Leigh Star -> Cas / Réf. / Sources
