# Structure de la thèse V3 — spécification visuelle

But:
Préserver la matrice chapitrale historique tout en améliorant la lecture ontologique.

Colonnes visibles:
1. Chap.
2. Struct.
3. Objets
4. Acteurs
5. Concepts
6. Evén.
7. Réf.

Lignes:
- Intro
- Chap. I
- Chap. II
- Chap. III
- Concl.
- Multi.

Règles:
- Les colonnes Chap. et Struct. ne doivent jamais être supprimées.
- Les couleurs et halos historiques sont conservés.
- Les personnes agissantes restent dans Acteurs.
- Les auteurs théoriques vont dans Réf.
- Les protocoles et UCN restent dans Objets.
- Les concepts structurants restent dans Concepts.
- Les événements et crises restent dans Evén.

Hiérarchie interne:
- Objets: MonetaryObject / Protocol / Software / Services / Domains
- Acteurs: catégories / institutions / groupes / personnes
- Concepts: core / secondary / technical / native formula
- Evén.: crise / phase / processus / micro-événement
- Réf.: cadre / ouvrage / corpus / citation / auteur de référence

Critère de réussite:
1. La vue reste familière.
2. Elle gagne en lisibilité.
3. Elle ne perd pas sa force visuelle.
