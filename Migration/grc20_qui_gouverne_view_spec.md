# Vue « Qui gouverne ? » — Recomposition proposée

## Intention
Cette vue doit répondre immédiatement à la question :
**qui gouverne réellement les cryptomonnaies, à quels niveaux, dans quelles arènes, et avec quels rapports entre catégories, groupes, organisations et personnes ?**

Elle doit montrer une hiérarchie de gouvernement :

1. catégories de parties prenantes ;
2. organisations / institutions ;
3. groupes empiriques ;
4. arènes de coordination ;
5. personnes agissantes ;
6. cas / crises ;
7. références / sources.

## Colonnes
1. Catégories
2. Organisations
3. Groupes
4. Arènes
5. Personnes
6. Cas
7. Réf.

## Lignes
1. Pouvoir distribué
2. Coordination
3. Décision
4. Conflit
5. Maintenance
6. Réf.

## Règles
- les personnes agissantes restent dans `Personnes` ;
- les auteurs théoriques et la bibliographie restent dans `Réf.` ;
- `Arènes` doit être une vraie colonne ;
- les crises servent de révélateurs de gouvernance ;
- conserver halos, lisibilité mobile et esthétique historique.

## Exemples
- Développeurs core -> Catégories / Pouvoir distribué
- Ethereum Foundation -> Organisations / Pouvoir distribué
- Core Developers (Bitcoin) -> Groupes / Décision
- GitHub Bitcoin Core -> Arènes / Maintenance
- Peter Wuille -> Personnes / Maintenance
- Greg Maxwell -> Personnes / Décision
- CVE-2018-17144 -> Cas / Maintenance
- The DAO -> Cas / Conflit
- Susan Leigh Star -> Réf.
